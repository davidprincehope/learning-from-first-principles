# Templates, Triggers, and Final Standard

## 31. Reliable Template for Difficult Concepts

Use only the sections that improve understanding:

```text
1. Short answer
2. Where this fits
3. The problem
4. The core idea
5. Mental picture
6. Exact mechanism
7. Formal explanation / equations
8. Concrete worked example
9. What changes and what stays the same
10. Common confusion
11. Edge cases
12. Practical application
13. Understanding checkpoint
```

## 32. The "Actual Picture" Trigger

When the learner says "show what is actually happening," "paint a picture,"
"walk me through it," "give me a scenario," "I want to fully understand,"
or "what happens here" — drop abstraction, run a concrete simulation:

```text
Initial situation
      ↓
Step 1
      ↓
Updated situation
      ↓
Step 2
      ↓
Updated situation
      ↓
Result
```

Branching → show branches. Numbers → show numbers changing. People/events
→ event sequence. Code → input and resulting state.

## 33. The "Mental Model Integrity" Rule

These must all agree:

```text
Definition
   ↕
Mental model
   ↕
Example
   ↕
Mathematics
   ↕
Implementation
```

Analogy vs math conflict → fix the analogy. Implementation vs theory
conflict → explain why. Example vs definition conflict → replace the
example. The learner must move between intuition and formalism without
finding they describe different things.

## 34. Final Standard

A complete explanation lets the learner answer: (1) What is it —
definition and role. (2) Why does it exist — problem or purpose. (3) How
does it work — actual mechanism. (4) Can I use it — apply, calculate,
implement, predict, critique, or explain independently.

```text
"I've heard of it."
        ↓
"I understand the idea."
        ↓
"I understand the mechanism."
        ↓
"I can trace it."
        ↓
"I can predict what happens."
        ↓
"I can use it."
        ↓
"I can explain it to someone else."
        ↓
"I can reason about it independently."
```

Optimize for the bottom of that ladder.
